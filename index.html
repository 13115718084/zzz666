01 / 一句话与公式

Sverdrup 理论：大洋内区（埃克曼层以下、远离西边界）的经向体积输送，完全由风应力旋度决定。

β V = (1/ρ) ( ∇ × τ )z　　，　　V = ∫ v dz

其中 V 是单位宽度的经向输送（m²/s），β = ∂f/∂y ≈ 2.3×10⁻¹¹ m⁻¹s⁻¹。

提出者H. Sverdrup, 1947最初用于解释赤道逆流
后来补齐Stommel 1948 / Munk 1950西边界强化与粘性边界层

三个要点先记住

要点说明
只给经向输送Sverdrup 只算 V（南北向），不管东西向，也不管流涡怎么闭合
内区无摩擦理论本身不含摩擦，但解必须靠西边界的摩擦来闭合
输送量可换算1 Sv = 10⁶ m³/s；V 乘洋盆宽度即总输送

与 TICKET 04「上层海洋的三种流动」第 06 节是同一条因果链，此处展开完整推导。

02 / 路线 A：地转 + 连续方程

第一步：内区地转流的水平辐散，只来自 β 效应。

∇·ug = ∂ug/∂x + ∂vg/∂y = − (β/f) vg

第二步：代入连续方程 ∇·u + ∂w/∂z = 0：

β vg = f ∂w/∂z　　←　Sverdrup 平衡（微分形式）

第三步：以埃克曼层底 w = wE 为上边界、海底 w = 0 为下边界垂向积分：

β V = f [ w(顶) − w(底) ] = f wE

第四步：代入埃克曼抽吸 wE = ẑ·∇×(τ/ρf)：

β V = (1/ρ) ( ∇ × τ )z

路线 B：位涡守恒

内区绝热无摩擦，位涡守恒 D[(ζ+f)/H]/Dt = 0，线性化 ζ ≪ f 后展开：

Dζ/Dt + β v = 0　　，　　(1/H) DH/Dt = ∂w/∂z

含 ζ 的项相互抵消，直接得到 β v = f ∂w/∂z。两条路线殊途同归。

03 / 物理图像：压扁 → 向赤道

把因果链画成一张经向剖面图（北半球副热带）：西侧为西风带、东侧为信风带，中间是流涡中心。

两句话概括正反两种情形

Squashing → equatorward

副热带反气旋风场 → 埃克曼下沉 → 水柱压扁（H↓）→ 位涡守恒要求 f↓ → 向赤道移动。

Stretching → poleward

副极地气旋式风场 → 埃克曼上升 → 水柱拉伸（H↑）→ 位涡守恒要求 f↑ → 向极地移动。

提醒：埃克曼抽吸是垂向的（向下/向上），Sverdrup 输送是经向的（南/北），两者互相垂直，前者是因、后者是果。

04 / 量级算例（可交互）

给定北边界（西风带）与南边界（信风带）的纬向风应力，以及它们的纬度跨度，就能算出整套量级。

curlz τ ≈ − ( τ北 − τ南 ) / Δy　　→　　wE = curl τ / (ρ f)　　→　　V = curl τ / (ρ β)
风应力旋度-7.50e-8 N/m³
埃克曼抽吸 wE-31.7 m/yr
经向输送 V-3.69 m²/s
总输送（跨洋盆）-18.5 Sv

当前为下沉抽吸，内区向赤道输送。

负值 = 南向（赤道向）。把 τN 与 τS 反过来，整个流涡旋向就反转。

量典型值说明

关键对比：内区宽（5000 km）× 慢（cm/s）；西边界窄（100 km）× 快（1–2 m/s）。输送量必须相等 —— 这就是西边界强化的本质。

05 / 五个关键假设

假设含义一旦破坏
线性、定常丢掉非线性平流与 ∂/∂t涡旋、瞬变过程无法描述
地转平衡Ro ≪ 1赤道（f→0）失效
β 平面f = f₀ + βy极区与赤道需另处理
内区无摩擦摩擦只在埃克曼层与西边界整个理论靠这个分工成立
底部无穿越流w(底) = 0地形抬升时需加底压扭矩

最微妙的一点：Sverdrup 理论本身不含摩擦，但它的解必须靠西边界的摩擦才能闭合。内区输送算出来是多少，西边界流就得还回多少；摩擦只决定"怎么还"，不决定"还多少"。

能解释什么、不能解释什么

能解释

  • 内区经向输送的大小与方向
  • 流涡中心纬度（curl τ = 0 处 V = 0）
  • 赤道流系与赤道逆流的位置
  • 风场变化后环流的调整（Rossby 波）

不能解释

  • 纬向流与流涡闭合（需 Stommel / Munk）
  • 西边界流的强度与结构
  • 热盐环流（Sverdrup 只管风生部分）
  • 赤道附近与瞬时变化
Sverdrup 给输送量　+　Stommel 给西向强化　+　Munk 给粘性边界层　=　完整风生环流

01 / 长波是什么：三类长波

波长远大于水深（浅水），或远大于变形半径的波动，统称长波。它们满足静力与准地转近似，垂向速度很小，水平尺度却可达数百到数千公里——是大洋调整与气候信号传播的主角。

区分它们的唯一标准是恢复力：被扰动后，究竟是什么力量把水团拉回原位。

波型 恢复力 频散关系 相速度 典型量级
浅水重力波 重力（层结时用 g′） ω² = g′h(k²+l²) √(g′h) 海啸 ≈ 200 m/s；内波首模 ≈ 2–3 m/s
惯性重力波 重力 + 科氏力 ω² = f² + g′h(k²+l²) ＞ √(g′h) 内波、潮频附近的振荡
罗斯贝波 β（行星涡度梯度） ω = −βk /(k²+l²+1/L_d²) 向西，≈ βL_d² 2–5 cm/s；跨洋盆约 10 年
开尔文波 重力 + 科氏力（被岸或赤道捕获） ω = ±√(g′h)·k 沿岸或沿赤道，√(g′h) 赤道 ≈ 2–3 m/s，向东

三条判据：一眼分辨它们

判断 结论
有没有科氏力参与？无 → 纯重力波；有 → 惯性重力波（频率下限为 f）
恢复力是不是 β？是 → 罗斯贝波，也是唯一相位恒向西的大尺度波
是否被边界或赤道捕获？是，且经向速度为零 → 开尔文波（单向、非频散）

02 / 浅水重力波与变形半径

线性化浅水方程（暂不加旋转）：

∂u/∂t = − g′ ∂η/∂x　　，　　∂η/∂t = − h ∂u/∂x

两式联立即得波动方程，相速度只由层结与厚度决定：

∂²η/∂t² = g′h ∂²η/∂x²　　→　　c = √( g′ h )

表层用重力 g 与水深 h ≈ 4000 m → c ≈ 198 m/s，这正是海啸的传播速度；内波则用约化重力 g′ = g Δρ/ρ₀，第一斜压模等效水深 h₁ ≈ 0.4–0.8 m → c₁ ≈ 2–3 m/s。

加上旋转：变形半径登场

ω² = f² + g′h ( k² + l² )

当波长超过变形半径时，旋转压过重力，运动从重力波过渡为准地转的涡旋与罗斯贝波。这个临界尺度就是变形半径：

L_d = √( g′ h ) / f = N h / f
正压（外）变形半径~2000–2700 km√(gH)/f，H ≈ 4000 m
第一斜压模 L_d30–50 km中纬度；也是中尺度涡的尺度

物理含义：旋转（f）与层结/重力（√(g′h) 或 Nh）相互竞争的临界尺度。小于它重力主导，大于它旋转主导——这正是中尺度涡恰好为几十公里的原因。

03 / 罗斯贝波：推导

从准地转位涡方程出发——它就是把位涡守恒写成流函数 ψ 的演化方程：

∂/∂t ( ∇²ψ − ψ / L_d² ) + β ∂ψ/∂x = 0

设波动解 ψ = Ψ ei(kx + ly − ωt)，记 K² = k² + l²，立即得到频散关系：

ω = − β k / ( k² + l² + 1/L_d² )
c_x = ω / k = − β / ( k² + l² + 1/L_d² )　＜　0

分母恒为正，所以相速度永远向西——不论波长多少、不论 k 取什么符号。这是罗斯贝波最标志性的特征。

两个极限与群速度

极限 条件 相速度 性质
长波极限K² ≪ 1/L_d²c = − β L_d²与波长无关，近似非频散
短波极限K² ≫ 1/L_d²c = − β / K²波长越短越慢，频散

群速度 c_gx = ∂ω/∂k 的符号可以变为正，意味着能量能够向东传播，而波峰（相位）始终向西移动。相位与能量反向，是常见考点。

频散关系图

物理图像：位涡守恒

水柱向南移动 → f 减小 → 为保持 (ζ+f)/H 守恒，必须获得正（气旋式）相对涡度 ζ → 该涡度异常诱导速度场 → 扰动继续传递，形成向西传播的波。

这与 Sverdrup 内区用的是同一条位涡约束：前者被风强迫成定常输送，后者作为自由波传播。β 之所以能充当恢复力，正因为它是行星涡度随纬度的梯度。

05 / 开尔文波与赤道波系

开尔文波的条件是垂直于岸（或跨赤道）的速度恒为零，沿岸方向满足地转平衡，振幅离岸按变形半径尺度指数衰减：

f u = g′ ∂η/∂x　　，　　c = √( g′ h )　（非频散）

传播方向：北半球（f＞0）沿岸传播时岸在行进方向的右侧，南半球相反。它由重力驱动，却被科氏力“贴”在边界上，因此只能单向传播。

赤道开尔文波

赤道是天然波导：f 在两侧反号，把波动“困”在赤道附近约一个变形半径宽的带内。赤道开尔文波向东传播，c ≈ 2–3 m/s，跨太平洋约需 2 个月。

它是 ENSO 的核心环节：西太平洋暖池的异常信号，正是靠赤道开尔文波东传，改变东太平洋的温跃层深度与海表温度。

02 / 谁主导失热？谁最小？

在许多海洋区域，潜热通量与蒸发紧密相关，常是重要的海洋失热项；但主导项取决于季节、风速、湿度、海气温差和区域。不能把某个排序当作全球固定规律。

通量物理过程常见解释符号（海洋得热为正）
Qs短波辐射太阳辐射进入海洋通常为正
Qb净长波辐射海洋与大气之间的红外辐射交换通常为负
Qe潜热通量蒸发带走热量通常为负，常较大
Qh感热通量海气温差引起的显热交换常较小，符号随温差而变
失热量级：比较 |Q|，而不是只看带符号的数值。

03 / 混合层深度（MLD）

混合层是海洋上层中温度、盐度或密度相对均匀的区域。常见密度判据之一是：相对于参考深度（常取 10 m），密度增量达到 Δσt = 0.03 kg/m³ 时对应的深度。不同研究也会采用温度阈值或其他密度阈值，需说明判据。

Δσt(z) = σt(z) − σt(zref) = 0.03 kg/m³

图为概念示意，不是观测剖面。实际判定需要逐层计算密度差，并找到首次达到阈值的深度。

为什么冬季混合层通常更深？

冬季海表冷却和风应力增强会使上层海水更容易发生对流与湍流混合；夏季表层受热、稳定分层增强，混合层往往变浅。区域环流、淡水输入与风场会改变这一季节性规律。

04 / 副热带北大西洋温盐剖面

典型副热带开阔海洋中，温度通常随深度下降；盐度剖面可能出现次表层盐度极大和更深处的盐度极小，反映水团形成、平流与混合的共同作用。以下是用于教学的典型化示意曲线，并非特定站位实测数据。

温度曲线总体递减
盐度曲线可有极大 / 极小

盐度极大常与高蒸发副热带表层水及其下沉/输送有关；盐度极小可与较淡水团的中层输送有关。具体深度与强度随经纬度和季节变化。

05 / 蒸发：控制因子与潜热换算

蒸发受海表与近海面空气的湿度差、风速、海表温度、稳定度和大气条件共同控制。风速增大、空气较干时，蒸发通常增强。

Qe ≈ ρw E Lv　；　Lv ≈ 2500 J/g

若蒸发量 E 以 mm/day 表示，1 mm 水层约等于 1 kg/m²。用 2500 J/g = 2.5×10⁶ J/kg，可估算每天蒸发带走的能量，再除以 86400 s 换算成 W/m²。

单位面积潜热损失7.50 MJ/m²/day
等效热通量86.8 W/m²

这是理想化潜热估算；实际海气通量还需考虑蒸发定义、密度与通量参数化。

06 / 大西洋 vs 太平洋盐度

在许多气候平均态资料中，北大西洋副热带表层盐度高于相应太平洋区域。重要机制之一是大气水汽跨中美地峡的净输送：水汽从大西洋侧蒸发，经大气输送后在太平洋侧降水，形成盐分的跨盆地转移。风场、降水、蒸发、河流与海洋环流也共同影响盐度。

双盆地机制示意图，不表示真实地理比例或定量水汽通量。

表层盐度变化 ≈ 蒸发 − 降水 + 平流 / 混合等影响

牢记：蒸发移走水、留下盐；降水增加淡水、稀释海水。海盆平均盐度差异不能只用单一机制解释。

07 / 混合层季节变化与 SST 滞后

季节变化由海表热通量、风应力和混合共同驱动。典型中高纬海域冬季混合层较深、夏季较浅；海表温度对太阳辐射季节变化的响应通常有热惯性，因此 SST 峰值可能滞后于太阳辐射峰值约 1–2 个月，但不是所有海域都固定如此。

冬季典型特征冷却 + 强风混合层通常更深
夏季典型特征表层受热稳定分层增强，混合层通常更浅

08 / 温跃层的维持机制

温跃层是温度随深度快速变化的区域。其结构受表面加热、风驱环流、垂向平流、湍流扩散和水团运动共同影响。简单的一维稳态概念方程可写为：

w ∂T/∂z ≈ ∂/∂z (Kz ∂T/∂z)

左侧表示垂向平流，右侧表示垂向湍流扩散。该式是简化的平衡示意；完整热量方程还包括水平平流、非稳态项和热源项。

Ekman 抽吸是风应力旋度驱动的上升流/下沉流之一种机制；通风则可将表层水团带入海洋内部。它们能影响温跃层的深度、斜率和水团更新，但具体效应取决于风场和环流背景。

EOF 是什么？

EOF（Empirical Orthogonal Function，经验正交函数）是一种从时空数据中提取主要变化模式的统计方法，与 PCA（主成分分析）密切相关。它把复杂数据表达为少数几个空间模态及其时间系数。

一句话理解：把一堆随时间变化的场，拆成「空间形状 × 时间强弱」的若干组合。

X(s,t) ≈ Σ EOFk(s) × PCk(t)
EOF 空间模态变化“长什么样”空间分布与相对符号
PC 时间系数何时强、何时弱该模式随时间的振幅变化

01 / 三种流动，一张对照表

上层海洋的运动看似复杂，其实可以拆成三种最基本的形态。它们的区别只有一个：哪几个力参与平衡。

对比项惯性流地转流埃克曼层
力的平衡科氏力 = 加速度压强梯度力 + 科氏力 = 0湍流摩擦 + 科氏力 = 0
压强梯度无必须有层内可忽略
摩擦 / 风应力无无必须有
加速度有（向心）无（稳态）无（稳态）
流动方向绕圈（惯性圆）沿等压线跨等压线（螺旋）
典型流速0.1–0.5 m/s0.01 m/s（内区）→ 2 m/s（西边界）0.1–0.3 m/s
时间尺度高频：2π/f ≈ 12–24 h定常 / 缓变（季节—多年）随风场（天—季节）
空间尺度半径 V/f ≈ 1–5 km10–100 km，或洋盆尺度厚度 10–50 m
失效位置赤道 f → 0赤道、强弯曲（Ro 大）赤道 f → 0

从同一个方程出发

三种流动其实是同一个水平动量方程在不同近似下的三个解。先写出完整的方程：

∂u/∂t + (u·∇)u + f ẑ×u = −(1/ρ)∇p + ∂/∂z( K ∂u/∂z )

依次为：局部加速度 · 平流加速度 · 科氏力 · 压强梯度力 · 湍流粘性项。

保留的项得到物理含义
加速度 + 科氏力惯性流无外力时靠科氏力打转
科氏力 + 压强梯度力地转流两力精确反向，沿等压线走
科氏力 + 湍流粘性（+风应力边界）埃克曼层风的动量被湍流往下传并被科氏力偏转

记忆法：谁被留下，谁就决定流动的性格。丢掉压强梯度 → 打转；丢掉摩擦和加速度 → 沿等压线；丢掉压强梯度和加速度、把风应力放到边界上 → 螺旋。

真实海洋：三者的垂向叠加

分工很清晰：埃克曼层负责把风接进来并提供垂向速度边界；地转流负责内部怎么走；惯性振荡是被扰动后的高频回响。

02 / 惯性流 Inertial flow

没有压强梯度、没有摩擦、没有风，只剩下科氏力。此时科氏力充当向心力，水质点做匀速圆周运动。

∂u/∂t = f v　　，　　∂v/∂t = − f u

用复数写法一眼看出解的结构：

u + i v = (u₀ + i v₀) · e− i f t

关键量

T = 2π / |f|　　R = V / |f|

周期 = 半个"摆日"；半径正比于流速、反比于 f。

旋向

两个半球都是反气旋式：北半球顺时针，南半球逆时针。速率恒定、能量不衰减（理想情况）。

惯性圆与典型数值

惯性周期 T23.93 h
惯性圆半径 R1.37 km
旋转方向反气旋（顺时针）

把纬度调到 0 试试：周期趋于无穷，惯性振荡消失。这就是赤道附近不能用 f 平面的原因。

记忆钩子

把惯性流想成"风停以后海面还在打转"：锚系观测里流速矢量一圈圈转、谱分析在频率 f 处出现尖峰，那就是惯性振荡。真实海洋中它总是叠加在平均流上，所以看不到纯粹的圆。

03 / 地转流 Geostrophic flow

压强梯度力与科氏力精确反向。流体想从高压流向低压，却被科氏力扳弯，最终沿着等压线（等海面高度线）横向流动。

f vg = (1/ρ) ∂p/∂x　　，　　f ug = − (1/ρ) ∂p/∂y
写法公式什么时候用
分量形式ug = −(1/ρf) ∂p/∂y，vg = (1/ρf) ∂p/∂x最基础，推导用
矢量形式ug = (1/ρf) ẑ × ∇p一眼看出方向关系
海面高度ug = −(g/f) ∂η/∂y，vg = (g/f) ∂η/∂x用卫星高度计算表层流
流函数ψ = p/(ρ₀f)，ug = −∂ψ/∂y，vg = ∂ψ/∂x理论推导、画图

方向口诀（北半球）：背流而立，高压在右、低压在左；南半球相反。科氏力永远垂直于速度，不做功，所以这是一个无能耗的稳态平衡。

力的平衡图解

g 压强梯度力（指向低压） 科氏力（指向高压） 两者大小相等、方向相反 北半球判定 高压 / 高海面 在右 流速 ∥ 等压线 科氏力 ⟂ 流速 南半球：全部左右互换

地转流速 vg0.135 m/s

什么时候地转近似不成立？

Ro = U / (f L)　（惯性力 / 科氏力）
Rossby 数含义典型场合

强弯曲处要升级为梯度风平衡：V²/R + f V = (1/ρ) ∂p/∂n，否则地转公式会系统性偏估。

04 / 热成风与动力高度

把静力平衡和地转平衡联立，就得到整个物理海洋学里最实用的一条关系：地转速度的垂向切变由水平密度梯度决定。

∂ug/∂z = ( g / ρ₀f ) ∂ρ/∂y　　，　　∂vg/∂z = − ( g / ρ₀f ) ∂ρ/∂x

矢量形式更紧凑：∂ug/∂z = −(g/ρ₀f) ẑ × ∇ρ —— 切变矢量平行于等密度线。

判定口诀（北半球）：背热成风而立，重（冷）水在左、轻（暖）水在右。

为什么上层流强、深层流弱？

海洋的温跃层里等密面大幅倾斜，密度梯度累积起来就形成"表层流核 + 深处减速"的典型剖面，这正是湾流、黑潮垂向结构的来源。

动力高度：把密度换算成流速

D = ∫ δ dp　　，　　δ = α(S,T,p) − α(35,0,p)
ug = − (1/f) ∂D/∂y　　，　　vg = (1/f) ∂D/∂x

这就是"动力计算法"：用 CTD / Argo 密度剖面算出动力高度 D，再取水平梯度得到相对流速。单位常用动力米（1 dyn m = 10 J/kg，数值上约等于 1 m 等效海面起伏）。

能算斜压部分速度随深度的切变
不能算正压分量整层一致的绝对流速

积分需要一个参考速度——传统上把它设为 0，称为无运动面；但深层并非静止，所以更诚实、更好的说法是已知运动面：承认参考速度必须由观测或反演给出。

05 / 埃克曼层与埃克曼螺旋

风应力在海面输入动量，湍流把它往下传，而科氏力在传递过程中不断偏转流向，于是形成著名的埃克曼螺旋。稳态、忽略压强梯度：

− f v = K ∂²u/∂z²　　，　　f u = K ∂²v/∂z²

边界条件：海面 ρ K (∂u/∂z, ∂v/∂z) = τ；深处 u → 0。经典解可写成：

u + i v = [ τ / (ρ √(2fK)) ] · (1 + i) · e(1+i) z / d
d = √( 2K / f )　（埃克曼层厚度尺度，典型 10–50 m）

其中 (1+i) = √2 eiπ/4 这一个因子，就是"表层流相对风向偏 45°"的由来（北半球右偏）。

埃克曼螺旋图解

实测中因层结、波浪和非定常风，表层偏角往往只有 10°–30°，而不是理论的 45°。

埃克曼输运：整层积分后的惊喜

把整个埃克曼层的流速对深度积分，涡粘系数 K 会被边界条件完全消掉，得到一个极其重要的结论：

ME = ( τ × ẑ ) / ( ρ f )　　，　　| ME | = τ / ( ρ f )
方向垂直于风北半球在风向右方 90°
与 K 无关只取决于 τ 和 f不管湍流多强，总输运不变

它是沿岸上升流（风平行海岸、输运送离岸）和赤道上升流的直接机制。

06 / 埃克曼抽吸与 Sverdrup 内区

埃克曼输运的水平散度必须由层底的垂向运动来补偿，这就是埃克曼抽吸：

wE = ẑ · ∇ × ( τ / ρf ) ≈ (1/ρf) ( ∂τy/∂x − ∂τx/∂y )
风应力旋度埃克曼输运垂向速度典型区域
正（气旋式）辐散上升 wE > 0副极地流涡
负（反气旋式）辐合下沉 wE < 0副热带流涡

典型量级：wE ~ 10⁻⁶ m/s ≈ 30 m/yr。数字很小，但它驱动的是整个大洋内区的经向输送。

从抽吸到 Sverdrup 关系

内区位涡守恒 + 线性化（ζ ≪ f），配合连续方程，可以直接由地转流推出：

β vg = f ∂w/∂z　　，　　β = ∂f/∂y

以埃克曼层底 w = wE 为上边界、海底 w = 0 为下边界积分，得到 Sverdrup 输送：

β V = f wE = (1/ρ) ( ∇ × τ )z

位涡图像（更直观）：反气旋风场 → 埃克曼下沉 → 水柱被压扁（H 减小）→ 位涡 (f+ζ)/H 要守恒就必须让 f 减小 → 水柱向赤道移动。这就是副热带流涡内区缓慢南向漂流的由来。

逻辑链图解

E 气旋式 → 上升 水柱伸缩 拉伸 / 压缩 → 位涡守恒 被迫改变纬度 改变行星涡度 f Sverdrup 输送 βV = curl τ / ρ 西边界流闭合 湾流 / 黑潮 内区：宽（洋盆尺度）× 慢（1–5 cm/s）　｜　西边界：窄（~100 km）× 快（1–2 m/s）

同样输送 30–40 Sv，内区用整个洋盆宽度和几 cm/s 完成，西边界只能用 100 km 宽度和 2 m/s 完成 —— 这就是西边界流强化。

位涡：把三者串起来的守恒量

形式公式
浅水位涡q = (ζ + f) / H
Ertel 位涡q = (1/ρ) ζa · ∇ρ ≈ f N² / g
守恒律Dq/Dt = 0（绝热、无摩擦）
浮力频率N² = − (g/ρ₀) ∂ρ/∂z

三个贡献因子：①相对涡度 ζ（自转）+ ②行星涡度 f（纬度）+ ③层结 H 或 N²（水柱厚薄）。三者之间的相互补偿，构成位涡守恒约束下海洋大尺度环流的骨架。

记忆钩子

风通过埃克曼层把动量泵进海洋，产生垂向抽吸；抽吸改变内区水柱厚度，位涡守恒迫使水柱改变纬度，形成地转的 Sverdrup 输送，最终由西边界流（湾流 / 黑潮）闭合；而风停之后，海面还在惯性地位打转。
