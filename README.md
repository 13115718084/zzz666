# 🌊 物理海洋学「出门票」学习网站

一个面向物理海洋学学习者的交互式知识学习与自测网站。通过知识梳理、动态图示、交互计算和随堂测试，帮助学习者理解海洋中的关键物理过程，并逐步建立系统的知识框架。

## 📖 项目简介

本项目以「出门票」为核心学习形式，将物理海洋学的重点知识拆分为若干学习任务。每张出门票围绕一个或多个核心概念展开，帮助学习者在学习后及时检验理解程度。

网站采用纯 HTML、CSS 和 JavaScript 构建，无需安装额外软件，可直接通过浏览器访问。

## 🧭 学习内容

### 出门票 01：海洋热量收支与温盐结构

* **海洋热量收支**：理解短波辐射、长波辐射、潜热通量和感热通量的物理意义及正负号。
* **混合层深度**：认识混合层的基本概念，理解基于密度变化判定混合层深度的方法。
* **温盐垂向结构**：了解温度、盐度随深度变化的基本特征，以及次表层盐度极大值和中层盐度极小值。
* **蒸发与潜热**：理解影响海洋蒸发的主要因素，并通过交互计算认识潜热与蒸发量之间的关系。
* **大西洋与太平洋盐度差异**：理解海洋间水汽输送及陆桥地形对盐度分布的影响。
* **季节变化**：认识混合层深度和海表温度的季节性变化，以及海洋热惯性带来的时间滞后。
* **温跃层维持机制**：了解垂向扩散、上升流、Ekman 抽吸和通风过程对温跃层的影响。

### 出门票 02：经验正交函数（EOF）

* 理解 EOF 的基本概念及其与主成分分析（PCA）的联系。
* 认识空间模态、时间系数和方差贡献率。
* 通过选择题检验对 EOF 核心概念的掌握程度。

后续将持续添加更多物理海洋学知识模块与自测题目。

## ✨ 网站功能

* **交互式图表**：调整热通量参数，观察不同热量收支项的变化。
* **示意图辅助理解**：通过垂向剖面图和过程示意图理解海洋物理机制。
* **实时计算**：根据输入参数计算蒸发相关的潜热变化。
* **季节切换**：观察不同季节下混合层与海表温度的变化特征。
* **知识自测**：通过选择题检验学习效果。
* **模块化扩展**：支持后续增加新的学习主题和自定义出门票。

## 📌 使用说明

1. 打开网站，选择对应的出门票。
2. 阅读知识讲解，观察图示并尝试交互操作。
3. 完成对应的自测题目。
4. 根据学习情况补充笔记，并继续学习后续模块。

**说明：** 网站中的部分剖面图与过程图为帮助理解概念而绘制的教学示意图，不代表特定海域的实测数据。涉及具体海洋现象时，应结合实际观测资料和相关文献进一步分析。
